# BlockVoluntariado

##  Descripción del Proyecto

**BlockVoluntariado** es una solución digital integral desarrollada para la startup **AlmasEnAcción**. Su objetivo principal es optimizar y modernizar la gestión de voluntariados, abordando las dificultades existentes en la conexión entre jóvenes, organizaciones no gubernamentales (ONGs) y especialistas de apoyo.

El proyecto fue desarrollado en el marco del curso de **IHC y Tecnologías Móviles** de la Universidad Peruana de Ciencias Aplicadas (UPC).

---

##  Segmentos Objetivo

La solución BlockVoluntariado está diseñada para impactar positivamente a tres segmentos clave:

* **Jóvenes Universitarios:** Para que encuentren oportunidades de voluntariado de forma sencilla y eficiente.
* **ONGs (Organizaciones No Gubernamentales):** Para facilitar la gestión, organización y difusión de sus campañas de voluntariado.
* **Psicólogos:** Para integrarlos en el ecosistema, ofreciendo posibles servicios de soporte o bienestar dentro de la gestión de voluntariados.

---

## ✨ Características Principales

BlockVoluntariado ofrece una serie de funcionalidades diseñadas para simplificar el proceso de voluntariado para todos los involucrados:

* **Plataforma de Conexión Inteligente:** Emparejamiento eficiente entre las habilidades e intereses de los **jóvenes universitarios** y las necesidades específicas de las **ONGs**.
* **Gestión de Voluntariados:** Herramientas para que las ONGs puedan crear, organizar, programar y hacer seguimiento a sus actividades de voluntariado de manera centralizada.
* **Perfiles Detallados:** Creación de perfiles completos para voluntarios y ONGs, lo que aumenta la transparencia y la confianza en la plataforma.
* **Integración de Soporte:** Facilita la interacción con **psicólogos** para integrar servicios de bienestar o soporte dentro de las actividades o programas de las ONGs.
* **Seguimiento de Progreso:** Módulos para que los voluntarios puedan registrar sus horas y las ONGs puedan evaluar el impacto de las acciones.
